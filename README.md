# Proyecto
Desarrollaremos una aplicación web estilo Trello, donde los usuarios puedan organizar proyectos y tareas en tableros colaborativos.

# Alcance (MVP)

* Usuarios con roles: Administrador y Usuario.
* Tableros: crear, editar y eliminar.
* Listas/columnas por tablero.
* Tarjetas/tareas: crear, mover entre columnas y marcar como completadas.
* Frontend en React con interfaz moderna.
* Extras (si el tiempo lo permite): notificaciones, etiquetas, estadísticas, exportación de tableros.
